# REPLAYD updates

The update manifest for [REPLAYD](https://replayd.download), its signature, and
the installers, mirrored here so an installation can still find an update when
replayd.download cannot be reached.

Nothing here is authoritative. The manifest is signed offline and every
installer is held to a hash inside those signed bytes, so REPLAYD trusts this
repository exactly as much as it trusts the website, which is not at all.

The site is the place to download REPLAYD: <https://replayd.download>
