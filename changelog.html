Changelog

What changed, and why.

Every version, newest first. The same notes the app shows before an update.

0.9.29

4 September 2026

  • The window draws its own title bar. The page's name sits in it, the sidebar runs to the top edge, and everything Windows does with a title bar still works: dragging, the double click, the right-click menu and the snap layouts over the maximise button.
  • Nothing opens a separate window any more. Adding a game, an entry's own settings, the options for one run, renaming a file and the warning before resetting all come up as a card over the page, with the page dimmed behind it.
  • Adding a game goes in steps. Pick from what is open, from what Steam, Epic and Riot have installed, by a rule about the window's title, or a display. Whether to record the whole session and any settings of its own are decided before the entry is added, and nothing already on the list is offered twice.
  • Game List is a place of its own in the sidebar, above the library. Rows show the program's icon, the order is explained above them, and Any game is always on the list: it can be switched off but not removed.
  • An entry's settings are under tabs by section, with the session switch first. The microphone can now be chosen per game and per run, and a title rule can be told to mind capitals.
  • Cards and blocks are lifted off the black background to the sidebar's own shade, so they can be seen. The folder a library page lists sits beside its tabs and opens Explorer when pressed.
  • Notifications are drawn in a face Windows can render sharply.

0.9.28

4 September 2026

  • Most of what was still in English in Spanish now is not. The Updates and License pages were built entirely in English, and so were the game list's own column headings, the buttons beside the profile and preset dropdowns, the warning shown before restoring the defaults, and the notes in the tray menu that say whether each half of REPLAYD is on or off.
  • The per game settings panel follows the same rules as the settings pages. It was offering a bitrate to type while automatic bitrate was on, and the rest of the pairs like it.
  • The row of buttons under the library is gone. Everything it did is on the right-click menu, most of it has a keyboard shortcut, and double clicking a file still opens it, so the row was a second way of saying the same thing that cost every page a line of space. Where the files are still sits in the corner.
  • The taskbar buttons could come up blank. Save is a floppy disk rather than a download arrow, which is what the button means in every game that has one.
  • Smaller things: the lines down the settings menu start below their heading instead of out of the middle of it, and the buttons on the window that asks for settings for one run have their labels centred.

0.9.27

4 September 2026

  • Hovering REPLAYD on the taskbar gives you five controls under the preview: stop or start the replay buffer, save the replay, save a clip, start or stop a recording, and take a screenshot. They are there while REPLAYD is behind whatever you are playing, which is most of the time.
  • The tray icon comes back on its own if Windows Explorer restarts. It used to go for good, which looks exactly like REPLAYD having quit while it is in fact still running and still recording, with no way left to reach it.
  • Windows calls both halves of REPLAYD by their right names now. The window is REPLAYD and the background half is REPLAYD Service, in Task Manager and anywhere else Windows names them.

0.9.26

3 September 2026

  • A browser at full screen is no longer mistaken for a game. It was recorded in place of one, and worse, it kept hold of the entry, so the game opened afterwards never took over.
  • Neither is a maximised window. If you play windowed and maximised there is now a setting for it under Recording, General: never, on the main monitor, or on any monitor.
  • A game is picked up as it opens rather than when you first click on it, and in about a second instead of up to twenty.
  • Alt+M marks the moment. The recording being made keeps the mark, and so does a replay saved afterwards that still reaches back far enough to contain it. Players show them as chapters.
  • The library works the way a folder window does: cut, copy, paste, rename, and dragging files out to anywhere else. Both listings also keep up with the folder now, so a file moved or deleted somewhere else stops being listed here without you having to leave the page and come back.
  • Automatic bitrate is lower, H.264 most of all. It could reach 120 Mbps on the codec whose files are already the largest, and on the machines least likely to have room for them.
  • The window fits on a smaller screen, and Home no longer has a scrollbar at its smallest. Quick Settings fills whatever width it is given rather than stopping at two rows.
  • The game list reads better on a narrow window. The Match by column is only as wide as its longest choice, and the three buttons on each row are icons.
  • Checking for an update answers the first press.

0.9.25

3 September 2026

  • Recording is smoother. The encoder was made to wait for each frame before the next one could be captured, which on a card with less headroom than the machine this was found on is where dropped frames come from.
  • Saving a replay no longer needs a second copy of it in memory. A five minute buffer at 4K was asking for gigabytes at the moment you pressed save, on a machine already running a game.
  • Notifications no longer cost you frames while you play. Anything drawn over a full screen game takes it out of direct presentation for as long as it is on screen, and a Windows notification costs exactly the same, so while the game being recorded is in front you now get the sound alone. There is a setting if you would rather see the notification, or hear nothing.
  • The notification sound is its own switch, so you can have one without the other, for all of them or for each kind.
  • A game stays the thing being recorded once you tab away from it. Starting a stopped buffer from the tray or the window used to find nothing, because clicking either of them is what took the focus off the game.
